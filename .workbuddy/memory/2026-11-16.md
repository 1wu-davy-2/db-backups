## 数据库备份平台（db-backups）调研

- 产出 `docs/01-research.md`：生态对比、技术选型、架构、DDL、PG 备份内核、保留策略算法、调度、里程碑。
- 核心结论：Databasus（Go+React，Apache-2.0）已覆盖约 90% 需求；自研需差异化（可验证恢复 / 国产化通知与对象存储 / CMDB 集成）。
- 关键事实更正：pgBackRest 2026-04-27 宣布停维护，2026-05-18 官宣继续，2026-10-18 发布 2.60.0（支持 PG 19）。网上多数对比文章已过时。
- 技术选型倾向：Go 1.24 + chi + PG 16 元数据库（用 `pg_try_advisory_lock` 做跨副本互斥）+ sqlc + robfig/cron v3 + React 19/Vite/shadcn。
